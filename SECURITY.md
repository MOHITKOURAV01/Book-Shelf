# Security Policy

Thank you for helping keep this project secure. We appreciate responsible disclosure of security vulnerabilities.

---

## Supported Versions

| Version | Supported |
| -------- | :-------: |
| Main (latest) | ✅ |
| Older versions | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not create a public GitHub issue**.

Instead, contact the project maintainers privately and include:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fix (if available)

We will acknowledge your report within **3–5 business days** and work to resolve confirmed vulnerabilities as quickly as possible.

---

## Responsible Disclosure

Please allow maintainers enough time to investigate and fix the issue before publicly disclosing any vulnerability.

---

## Security Best Practices

Contributors are encouraged to:

- Keep dependencies up to date.
- Never commit API keys, passwords, or secrets.
- Validate and sanitize all user inputs.
- Follow secure coding practices.
- Review third-party dependencies for known vulnerabilities.

---

## Security Updates

Security patches will be released for the latest supported version of the project. Users are encouraged to keep their local copies up to date.

Thank you for helping improve the security of this project!
